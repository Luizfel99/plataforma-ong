# Atividade 4 - Deploy

Esta atividade prepara o projeto completo com HTML, CSS e JavaScript para deploy.

## Instruções para Publicar no GitHub Pages

1. Certifique-se de que seu repositório está no GitHub.
2. Faça commit e push de todos os arquivos (index.html, style.css, script.js, README.md).
3. Vá para as configurações do repositório (Settings > Pages).
4. Selecione a branch principal (main) e a pasta raiz (/root).
5. Clique em "Save" e aguarde alguns minutos para o site ser publicado.
6. O link do seu site será algo como: `https://seu-usuario.github.io/nome-do-repositorio/`
